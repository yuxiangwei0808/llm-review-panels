  The reconstruction instrument. The model rates the severity of each item it itself

sources:
  severity_taxonomy: >
    Base taxonomy from PRISM (arXiv 2605.26730), the only published severity instrument in
    the peer-review domain. PRISM classifies flaws as Critical (methodological errors,
    flawed proofs) or Minor (typos, formatting) and weights them 2:1.
  delta: >
    We EXTEND PRISM's two levels to four (minor / moderate / major / fatal, weights
    1/2/4/8) because the two instruments do different jobs. PRISM uses severity for
    PRIORITIZATION -- checking whether critical issues are raised before minor ones -- and
    two levels suffice to rank. We use it for RECONSTRUCTION, mapping graded items onto the
    six-point ICLR scale, where two levels collapse most papers onto identical S_rec values
    and the resulting ties both depress AUC and blur the faithfulness gap we are measuring.
    PRISM's 2:1 weights also come from their nCPS ranking formula rather than from any
    score reconstruction, so borrowing them is a repurposing either way.
    The extension is reported as such: `prism_binary` is carried as an aggregation sweep
    variant (major+fatal -> Critical, minor+moderate -> Minor) so the fully-sourced coarse
    instrument is always shown beside ours. It is pure recomputation and costs no calls.
design_notes: >
  Three properties are load-bearing and must not be relaxed:
  (1) NO overall score is requested -- if the model emits a number here, the reconstruction
      is contaminated by a second holistic judgment.
  (2) The model's own call-A rating is withheld, so it cannot anchor on it.
  (3) Item order is shuffled upstream, so position cannot encode the original ranking.
  The separate-call design is itself a limitation (the model may rate items differently
  out of context); the A_samecall arm exists to measure that.
  For B3 this same prompt is used with items generated by a DIFFERENT model, which is why
  the text never says "your own" items.
  The per-item `justification` is public evidence-grounded reasoning, not private
  chain-of-thought. It must not disclose the severity label or self-reported confidence;
  both are withheld from the later fixed verifier.

Below are the strengths and weaknesses raised about one {venue_name} submission, together
with where in the paper each point comes from. They are listed in arbitrary order.

Rate how much each point matters for the paper's fate. Judge each item on its own terms,
against the standard you would apply as a {venue_name} reviewer.

## Rating vocabulary

For **weaknesses**:

| Label | Meaning |
|---|---|
| `minor` | Worth fixing, but does not affect whether the work stands |
| `moderate` | A real shortcoming that a reader should weigh against the contribution |
| `major` | Substantially undermines the contribution as claimed |
| `fatal` | Invalidates a central claim; the paper cannot stand as written |

For **strengths**:

| Label | Meaning |
|---|---|
| `minor` | A nice property, but not a reason to accept |
| `moderate` | A genuine contribution that counts in the paper's favour |
| `major` | A substantial contribution that would carry real weight |
| `decisive` | On its own a compelling reason to accept |

For every item, first provide a concise public justification grounded only in the stated
point and paper context. Explain what makes the point more or less consequential without
using any of the exact rating-vocabulary words `minor`, `moderate`, `major`, `fatal`, or
`decisive`, and without stating the severity label you selected or a numeric confidence
value. This justification will be shown to a separate verifier with your selected label
and self-reported confidence hidden.

Also give a confidence between 0.00 and 1.00 for each rating for historical compatibility:
how sure you are that this is the right label for this item, given the evidence stated.
This self-reported value is stored but is not the study's verifier-based confidence.

## Constraints

- Rate **every** item listed, using its exact `item_id`.
- Do **not** assign an overall score or recommendation for the paper. That is not the task
  here, and any overall judgment you state will be discarded.
- Do **not** introduce new criticisms or strengths. Rate only what is listed.
- Give every item a nonempty `justification`.
- Do **not** disclose the selected severity or numeric confidence inside `justification`.

## Output format

Return **only** a JSON object matching this structure, with no surrounding prose or code
fences:

```json
{
  "ratings": [
    {
      "item_id": "<exact id from the list>",
      "justification": "<concise public rationale without the severity label or confidence>",
      "severity": "<label>",
      "confidence": <0.00-1.00>
    }
  ]
}
```
